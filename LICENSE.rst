Attribution
-----------

If you are to include any of the generated files in your project, we
appreciate, *but do not require*, adding a heading like this:

.. code-block:: shell

    # Auto-generated file
    # Please submit all updates and bugfixes to https://x86-cpuid.org

This way, contributors can know about this project and `submit fixes`_
here instead of at the downstream project itself — benefiting the whole
ecosystem.
